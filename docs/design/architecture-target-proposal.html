记录 · SQLite the record

总线 · 变更流 bus
和记录同一事务写入；有界、有序、可回放；订阅者的游标就是 id
推送只是加速；落后就按 id 补，旧行被清理就明说最早 id。
更新 release
版本、自更新、修复任务

重启、退避、隔离；每次变动进记录
